# Versemend — business use at TDS

**What it is.** A structured training game that teaches Lua, the scripting language embedded in a wide range of modern tooling. It is a real curriculum, not a toy: eight domains of gated exercises whose checks are self-verifying, including adversarial cases where the player must find why a plausible-looking draft is wrong, and boss challenges such as running hostile guest modules inside a sandboxed plugin host. Rust host with Lua content; Android and desktop.

**Business case.** Training: self-paced scripting fluency for technical staff, at no cost. Advancement requires demonstrated mastery — the current build passes 464 of 464 self-checks — so completion is measurable without an external assessment.

**Risk posture.** Offline single-player; no network features; no data collection; progress is stored on the device only. Open source under Apache License 2.0.
