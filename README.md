# Versemend

A fantasy RPG that teaches deep Lua — the runtime, metatables,
coroutines, the C API, and embedding — by making the player write real
programs in the old tongue to mend a kingdom whose enchantments are
failing.

Spells in this world are verses: written, testable, breakable. As an
apprentice of the Spellwright's Guild you travel four regions — town,
trouble, trial — repairing enchantments under fourteen guild masters.
Each master's trial is a boss gate that is not a quiz but a verified
program: your own Lua, run against real checks, half validation and
half adversarial. Techniques are dual-use field verbs — a spell that
moves a stone in the world is the same idiom that moves data in a
program — and the combinations you hold become your build. Defeat is
backlash to the last town; knowledge is never taken from you. The
dialect taught is Tiger Style Lua: contracts before code, bounded
loops, errors as values, one owner for every piece of state.

## Status

In design. The concept, curriculum, and game design are complete and
gated; the engine selection is the game's own open commission and
production has not yet begun. This repository is the game's home:
design documents land first, then the build.

- **Platforms:** Android, Linux, and Windows — phone-first, fully
  offline, the complete game winnable on each.
- **Release model:** free. No ads, no in-app purchases, no accounts,
  no telemetry.
- **Narration:** synthetic, keeper lines only; everything else is text.
